# 小红书 · 企业微信外观（Edge）

为小红书桌面网页版提供企业微信风格的导航、会话列表与讨论区。
这是非官方项目，与小红书、腾讯及企业微信不存在官方关联。

本仓库用于发布扩展介绍、隐私政策和接收问题反馈。

## 项目信息

- 发布者：yangyq
- 扩展版本：0.1.0
- 皮肤版本：0.6.6
- 平台：Microsoft Edge 桌面浏览器
- 商店状态：上架准备中，商店链接将在发布后补充

## 主要功能

- 企业微信风格的侧栏、笔记会话列表、笔记详情和评论展示。
- 沿用小红书原生搜索、内容加载和评论交互。
- 支持皮肤开关及浅色、深色、跟随系统三种颜色模式。
- 扩展弹窗与页面内的外观设置在同一浏览器配置文件中保持一致。

部分企业微信风格导航项仅用于外观呈现，本扩展不提供邮件、会议或企业微信办公服务。

## 隐私政策

[查看隐私政策](PRIVACY.md)

扩展在本地处理当前小红书页面已加载的内容，持久保存的设置只有皮肤开关与颜色模式。
详细的数据访问和使用方式见隐私政策。
